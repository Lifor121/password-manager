# База данных менеджера паролей

## Описание
Эта папка содержит SQL скрипты для инициализации и управления базой данных PostgreSQL для Zero-Knowledge менеджера паролей.

## Структура таблиц

### users
Таблица пользователей с Zero-Knowledge аутентификацией.
- `id` UUID - первичный ключ
- `email` VARCHAR(255) UNIQUE - email пользователя (уникальный)
- `auth_hash` VARCHAR(255) - хэш мастер-пароля (KDF на клиенте)
- `crypto_salt` VARCHAR(255) - соль для криптографических операций
- `encrypted_vault_key` TEXT - зашифрованный симметричный ключ хранилища
- `created_at`, `updated_at` TIMESTAMPTZ - временные метки

### sessions
Таблица сессий для Bearer-токенов аутентификации.
- `id` UUID - первичный ключ (используется как Bearer-токен)
- `user_id` UUID - внешний ключ к users (каскадное удаление)
- `device_info` VARCHAR(255) - информация об устройстве (обрезается до 255 символов)
- `is_revoked` BOOLEAN - флаг отзыва сессии
- `expires_at` TIMESTAMPTZ - время истечения сессии (TTL 12 часов)
- `created_at` TIMESTAMPTZ - временная метка создания

### vault_items
Таблица зашифрованных паролей пользователей.
- `id` UUID - первичный ключ
- `user_id` UUID - внешний ключ к users (каскадное удаление)
- `encrypted_title` TEXT - зашифрованное название сервиса
- `title_blind_index` VARCHAR(255) - слепой индекс для поиска по названию
- `encrypted_login` TEXT - зашифрованный логин
- `encrypted_password` TEXT - зашифрованный пароль
- `encrypted_url` TEXT - зашифрованный URL (опционально)
- `encrypted_comment` TEXT - зашифрованный комментарий (опционально)
- `created_at`, `updated_at` TIMESTAMPTZ - временные метки

## Использование скриптов

### Инициализация базы данных
```bash
psql -U your_username -d your_database -f init.sql
```

### Обновление структуры
```bash
psql -U your_username -d your_database -f update.sql
```

### Загрузка тестовых данных (только для разработки!)
```bash
psql -U your_username -d your_database -f test_data.sql
```

## Индексы

### Основные индексы
1. `idx_users_email` - для быстрого поиска по email
2. `idx_sessions_user_id` - для поиска сессий пользователя
3. `idx_sessions_expires_at` - для очистки истекших сессий
4. `idx_sessions_is_revoked` - для фильтрации отозванных сессий
5. `idx_vault_items_user_id` - для получения паролей пользователя
6. `idx_vault_items_title_blind_index` - для поиска по слепому индексу

### Дополнительные индексы (из update.sql)
1. `idx_sessions_active` - частичный индекс для активных сессий
2. `idx_sessions_id` - для быстрого поиска по ID сессии

## Принципы безопасности

1. **Zero-Knowledge**: Мастер-пароль никогда не передается на сервер
2. **Bearer-токены как UUID**: Каждая сессия имеет уникальный UUID
3. **Каскадное удаление**: При удалении пользователя удаляются все связанные данные
4. **TTL сессий**: Сессии автоматически истекают через 12 часов
5. **Слепые индексы**: Поиск по зашифрованным данным через хэши

## Примечания для разработки

- Все данные в `vault_items` шифруются на клиенте перед отправкой
- `title_blind_index` используется для поиска без расшифровки названий
- Триггеры автоматически обновляют `updated_at` при изменениях
- Тестовые данные содержат фиксированные UUID для воспроизводимых тестов
